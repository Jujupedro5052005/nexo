numéricos são sintéticos e não constituem dados das empresas citadas. As fontes
externas são referências para consulta, não uma autorização para copiar obras.

O catálogo local identifica conteúdo por SHA-256, caminho canônico e versão.
A aplicação importa esses arquivos sem chamadas Gemini; o File Search é um
índice externo opcional, sincronizado somente sob autorização. Um documento
revisado como referência não cria fórmula executável. Os métodos operacionais
ficam no código e no registro de metodologias aprovado, com testes próprios.
Taxas constantes dos exemplos não representam a Selic atual, o custo de capital
de uma companhia ou uma previsão. Dados macroeconômicos recentes precisam ser
consultados na fonte com sua data de divulgação.
