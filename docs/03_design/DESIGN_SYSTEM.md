# Design system do Nexo Invest

Este documento é a fonte de verdade visual. Ele não define regras de domínio ou
persistência.

## Estado

O design system ainda não foi definido. Cores, tipografia, espaçamento, ícones,
componentes, gráficos, navegação e temas devem ser especificados durante a fase
de estrutura visual e validados na interface PySide6.

## Princípios já aplicáveis

- clareza antes de densidade;
- valores financeiros legíveis e com unidade/moeda explícita;
- estados positivos, negativos e neutros não dependem somente de cor;
- gráficos devem comunicar dados reais e possuir rótulos ou alternativas
  acessíveis;
- componentes repetidos devem manter aparência e comportamento consistentes;
- estados vazio, carregando, indisponível, sucesso e erro devem ser previstos.

Tokens e especificações concretas só devem ser registrados depois de uma
decisão visual, sem valores provisórios apresentados como definitivos.
